01
Background & Challenge

背景与挑战

作为面向企业的知识服务平台，国内知名科创服务企业的产品的用户期望越来越高的智能化体验——从知识问答到智能推荐。SaaS 平台做 AI 原生升级天然有三个难点：

产品需要 AI 原生能力

用户期望智能问答、智能推荐成为产品标配，传统关键词检索已无法满足，体验差距直接流失用户。

数据知识整合复杂

企业数据、政策、专利、行业资讯多源异构，整合与实时更新难度大，AI 答非所问风险高。

AI 能力交付节奏紧

产品迭代快，市场窗口短，需要快速把 AI 能力嵌入产品，自建团队周期长、试错成本高。

管理层最终确认的方向是：不把 AI 当外挂功能，而是以 FDE 现场共创的方式，把智能体原生嵌入产品体验，让企业用户真正用得起来。

02
Solution

解决方案：问答 · 推荐 · 生成 · 检索四类智能体

信朴科技以 FDE 现场共创、五步法交付，把 AI 能力原生嵌入 SaaS 产品体验：

问Q&A

知识问答 Agent · 让用户问得到

接入企业数据、政策、专利知识，构建产品级知识问答 Agent，自然语言问数、问政策、问专利，体验从检索升级为对话。

荐Recommend

智能推荐 Agent · 让用户发现得到

基于用户行为与知识图谱，构建智能推荐 Agent，主动推送相关政策、专利、资讯，提升用户活跃与留存。

生Generate

文档生成 Agent · 让用户写得快

构建文档生成 Agent，辅助用户生成申报材料、分析报告、商业文档，把知识服务从「找到」延伸到「写好」。

管Govern

Token 供应 + 用量治理

统一 GPT、Gemini 等模型供应渠道，用量约官网 45 折；建立产品级用量看板与成本治理，支撑 SaaS 商业模式可持续。

03
Implementation

实施路径：五步法交付

Phase 1 第 1–2 周

场景定义与产品对齐

深入产品、研发、运营访谈，梳理产品体验差距，按「用户价值 × 技术可行性」筛选出问答、推荐、生成、检索四类首批场景。

Phase 2 第 3–4 周

知识流程与数据接入

接入企业数据、政策、专利、行业资讯多源数据，构建知识库底座，明确数据更新机制与权限边界。

Phase 3 第 5–8 周

原型开发与产品集成

FDE 团队驻场开发四类 Agent 原型，与产品研发团队协同集成，完成产品级体验联调。

Phase 4 第 9–12 周

灰度测试与迭代

在部分企业用户中灰度测试，每周迭代；Token 统一供应与用量治理同步上线，支撑 SaaS 商业模式。

Phase 5 第 13–16 周

全量发布与交接

灰度验证后全量发布，4 类智能 Agent 上线；知识资产与 SOP 全量交接给客户研发团队，持续陪跑新场景。

04
Results

落地成果

项目交付后一个季度，各项指标持续向好：4 类智能 Agent 上线，知识问答、智能推荐、文档生成、智能检索覆盖核心体验；用户活跃提升 30%，AI 原生体验带动留存；模型用量成本稳定在官网约 45 折，支撑 SaaS 商业模式可持续。

更重要的是产品形态的变化——AI 从外挂功能变成了产品的核心体验，用户开始主动反馈新的智能化需求，产品竞争力明显上一个台阶。
